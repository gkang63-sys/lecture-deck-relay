Cowork 검증 — 기존 스킬로 한 번 더

Cowork는 Claude 앱의 작업 창입니다. 이번 학기 내내 덱을 만들던 스킬(english-lecture-deck · lecture-deck-audio · lecture-deck-video)을 기준으로 Claude Code와 Codex가 만든 최종본을 다시 읽었습니다.

Cowork가 잡은 것

  • 제목을 두 번 읽음 — 따옴표 모양만 다른 같은 제목 (다섯 장)
  • 빗금(/)이 「or」로 읽힘 — 끊어 읽기 표시가 소리로 (두 장)
  • 교사용 지도서의 지시문이 학생 화면에 그대로
  • 표 머리 칸의 대문자 변환으로 발음기호가 /ÆZ/로
  • 번역이 요지만, 낭독이 앞부분만 — 문장마다 번역 · 제목부터 끝까지 낭독으로

다음부터는 코드가 먼저

  • Claude Code가 Cowork의 수정을 하나씩 비교 · 확인한 뒤 받아들이고 기록(⑤′)
  • 낭독 · 화면 점검(narration_lint)을 검사 코드에 넣음 — Cowork 이전 본에 돌리면 Cowork가 찾은 것과 같은 8건, 최종본은 0건
  • 「번역 얇음 · 낭독 얇음」 경고 — 고치기 전 판에서 번역 7 · 낭독 16을 잡고, 고친 판은 0 · 2
  • ④ Codex의 검토 규칙에도 같은 항목을 더함

  • GPT는 이어달리기 코드의 결함(남은 단계를 보지 않음)도 찾음
