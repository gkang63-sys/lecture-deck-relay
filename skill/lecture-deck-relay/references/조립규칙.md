# ③ 조립 (claude)

## 1. ② 검토부터

`작업/review_plan_gpt.json`의 항목마다 받아들임 · 유지 · 절충을 정하고 `작업/decisions.json`에 적는다(형식은 최종규칙.md 2절). 받아들인 전사 차이는 `작업/원문.md`를 고친다 — 고쳤으면 `check.py plan`이 다시 통과해야 한다.

## 2. 공구와 조립

1. `python "<스킬>/scripts/run.py" setup` — deck_lib · narrate · verify · make_audio · vid/secvid를 `작업/build/`로 복사한다(있는 파일은 두고).
2. 지면 크롭: `작업/쪽/`의 그림에서 상자 · 문항 단위로 잘라 `작업/build/pages_b64.json`({키: data URI})을 만든다.
3. `작업/build/build.py`를 쓴다 — plan.json의 장마다 Deck 메서드 한 번(`d.slide` · `d.page` · `d.ix_*` · `d.divider` · `d.video` …). **장 순서와 수는 계획표와 같다.** 초안에서는 영상 장을 건너뛴다.
   - 스타일 원본은 직전 차시 덱(`DECK_SRC` 환경변수).
   - 대본 줄(`script([(spk, text)])`)의 text는 원문.md의 문장 그대로.
4. 초안: `NO_TTS=1 NOVIDEO=1 python "<스킬>/scripts/run.py" build.py` → 덱을 `출력/초안/<meta.file>.html`로 쓴다. 다른 HTML을 이 폴더에 두지 않는다.

## 3. 마무리

`python "<스킬>/scripts/check.py" draft` — ① 계획 재검사 · ② 결정 누락 · 넘침 · 노트 · 연습 채점 동작 · 장 수 · 대본 줄 원문 대조. 통과하면 GPT가 볼 `출력/초안/화면/`(슬라이드 그림)과 `slides.json`(슬라이드별 글)이 생긴다.
통과하면 `status.py claude`로 다음 차례(④ GPT)를 보고하고 멈춘다.
