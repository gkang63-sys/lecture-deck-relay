# 강의 덱 이어달리기 (lecture-deck-relay)

**이 파일 하나를 GPT(Codex)와 Claude가 똑같이 읽는다.** 규칙은 같고, 맡는 단계만 다르다.
덱을 만드는 규칙의 원본은 스킬 `english-lecture-deck` · `lecture-deck-audio` · `lecture-deck-video`(Codex: `lecture-deck-video-tts`)다. 이 스킬은 그 일을 두 AI가 나눠 하도록 순서와 파일 이름을 정한 것이다.

이 SKILL.md가 있는 폴더를 아래에서 `<스킬>`이라 부른다. 코드는 `python "<스킬>/scripts/이름.py"`로 부른다(표준 라이브러리만 쓴다).
**차시 폴더**는 지금 작업 폴더다(사용자가 다른 폴더를 말하면 그 폴더). 코드는 지금 작업 폴더를 차시 폴더로 본다.

## 1. 나는 누구인가

- Codex · ChatGPT에서 돌고 있으면 **gpt**. 맡는 단계: ② 계획 검토, ④ 덱 검토. **덱 파일과 build 코드는 쓰지 않는다.**
- Claude(Claude Code · Cowork · claude.ai)에서 돌고 있으면 **claude**. 맡는 단계: ① 계획, ③ 조립, ⑤ 최종.

## 2. 「다음 차례 해 줘」 — 언제나 이 순서

1. `python "<스킬>/scripts/status.py" <나>` 를 돌린다(`<나>`는 gpt 또는 claude).
2. **내 차례가 아니면** 출력된 문장(누구를 기다리는지)을 그대로 보고하고 멈춘다. 기다리며 지켜보지 않는다.
3. **내 차례면 그 단계 하나만** 한다. 끝나면 `status.py`를 다시 돌려 다음이 누구 차례인지 보고하고 멈춘다. 다음 단계가 내 것이어도 이어서 하지 않는다 — 한 번 부르면 한 단계.

| 단계 | 누가 | 먼저 읽을 규칙 | 쓰는 파일 | 마무리 코드 |
|---|---|---|---|---|
| 준비 | 아무나 | — | `작업/쪽/` | `prepare.py` (`작업/쪽/목록.json`이 없을 때만) |
| ① 계획 | claude | `references/계획규칙.md` | `작업/원문.md` · `작업/plan.json` | `check.py plan` |
| ② 계획 검토 | gpt | `references/계획검토규칙.md` | `작업/review_plan_gpt.json` | `check.py review_plan` |
| ③ 조립 | claude | `references/조립규칙.md` | `작업/build/` → `출력/초안/` | `check.py draft` |
| ④ 덱 검토 | gpt | `references/덱검토규칙.md` | `작업/review_deck_gpt.json` | `check.py review_deck` |
| ⑤ 최종 | claude | `references/최종규칙.md` | `작업/decisions.json` → `출력/최종/` | `check.py final` |
| ⑤′ 반영 | claude | `references/최종규칙.md` 5절 | 다른 도구(Cowork 등)가 ⑥ 전에 최종본을 고쳤을 때: 차이 비교 → `작업/검토_반영_<날짜>.md` → 처음부터 다시 만들기 | `check.py final` |
| ⑥ 확정 | 교수 | — | `출력/최종/`의 덱을 넘겨 보고 게시 | — |

### 실제 제작의 기본값 (2026-10-13 결정)

ELS1 6-1 연습에서 잰 값: GPT 이의 10건 가운데 7건이 Claude와 코드가 놓친 것(대본이 정답을 미리 보여 주는 순서 · 빠진 교재 질문 · 덱 공구 결함 2 · 안내 글 잘못 · 틀린 장 번호 · 열린 활동 채점), 틀린 지적 1건. GPT가 일한 시간 13분 23초, 교수가 앱 사이에서 넘겨 주기를 기다린 시간 약 35분.
→ **검토는 값어치가 있고, 비용은 사람의 전달에서 나온다.** 그래서:

- **② 계획 검토는 기본으로 건너뛴다.** 새 교재 · 새 단원 · 과제 조건이 바뀐 주처럼 원문 대조가 특히 필요하면 `입력/운영.md`에 `계획 검토: 켬` 한 줄. ④ 덱 검토 한 번이 구조와 화면을 함께 본다(낭독 · 영상 전이라 고쳐도 다시 만들 것이 적다).
- **GPT 차례는 Claude가 직접 부른다**: `python "<스킬>/scripts/ask_gpt.py"` — Codex CLI(`codex exec`)에 같은 한 줄을 주고 기다린다. GPT는 앱에서와 똑같이 이 스킬을 읽고 자기 단계만 한다. 교수가 넣는 말은 Claude에 「덱 만들어 줘」 한 번과 확정.
- Codex 앱에서 직접 「다음 차례 해 줘」를 넣는 방식도 그대로 쓸 수 있다(시연 · 교육용).
- GPT의 지적은 근거를 확인한 뒤 결정한다 — 지면 근거는 원 해상도 그림으로(틀린 지적 1건의 교훈).

## 3. 지킬 것

- **한국어는 영어 문장마다, 낭독은 제목부터 화면 영어 전부.** 요지 · 앞부분만은 안 된다(2026-10-15 교수 지적). 교재 지면 장 뒤에는 문장 단위 번역 장, 지면 장의 낭독은 지면 글 전체. 섹션 표지 · 영상 장만 낭독 없음. 코드가 「번역 얇음 · 낭독 얇음」을 `덮개_경고.json`으로 짚는다 — 기준은 `references/조립규칙.md` 3절.
- **인용은 원문 그대로.** 교재 본문 · 듣기 대본 · 정답은 `입력/`의 교재 · 지도서 · 교안에서만 가져온다. 기억으로 복원하지 않는다. `작업/원문.md`가 덱 안 인용의 기준이고, 코드가 덱의 대본 줄과 원문.md를 글자 단위로 대조한다.
- **이의 · 제안에는 근거를 붙인다.** 쪽 번호와 원문 인용, 또는 슬라이드 번호와 화면의 문장. 「내 판단과 다르다」는 이유가 아니다.
- **쓰는 곳.** claude는 `작업/`과 `출력/`. gpt는 `작업/review_*_gpt.json`과 `작업/검토메모/`뿐이다. 이 스킬을 부른 것이 그 안의 자기 결과 파일을 만들고 다시 쓰는 허락이다. `입력/`과 `<스킬>`은 고치지 않는다.
- **같은 이름으로 저장하지 않는다.** Windows는 파일 이름의 대소문자를 가리지 않는다. 다른 AI가 쓴 파일과 이름이 같거나 대소문자만 다른 파일을 만들지 않는다.
- **게시하지 않는다.** JNUclass 업로드 · 과제 예약 · 공지는 교수가 한다.
- 교재 지면과 지도서 원문은 저작물이다. 이 폴더 밖(공개 저장소 · 블로그)으로 내보내지 않는다.

## 4. 차시 폴더

```
입력/교재.pdf          교재 지면(스캔)
입력/지도서.pdf        교사용 지도서(대본 · 정답)
입력/교안.docx         작년 교안 (있으면)
입력/운영.md           과목 · 주차 · 차시 · 교재 쪽 · 일정 · 과제 조건 · 자습/강의실 · 다루지 않을 범위 (교수가 쓴다)
작업/쪽/               prepare.py가 뽑은 쪽 그림 (교재_1.jpg … · 지도서_1_좌상.jpg …)
작업/원문.md           ① claude가 지면에서 옮겨 적은 원문 (쪽 표시)
작업/plan.json         ① 슬라이드 계획표
작업/review_plan_gpt.json   ② 계획 검토
작업/build/            ③ 조립 코드 · 낭독 캐시 · 영상 대본
작업/review_deck_gpt.json   ④ 덱 검토
작업/decisions.json    ⑤ 이의 · 제안마다 받아들임/유지/절충과 근거
작업/검사/             코드 검사 결과 (단계 완료 표시)
출력/초안/             ③ 덱 초안 + 화면/(슬라이드 그림) + slides.json(슬라이드별 글)
출력/최종/             ⑤ 덱 · LMS판 · PDF · 낭독대본 · video/
```

새 차시를 시작할 때 `입력/`에 교재 · 지도서 · 운영.md가 없으면 교수에게 무엇을 넣어야 하는지 말하고 멈춘다.

## 5. 실행 환경 (claude 단계)

조립 · 낭독 · 영상 · 검사는 파이썬 가상환경과 Chrome이 필요하다. `python "<스킬>/scripts/run.py" <작업/build 안의 스크립트> [인자]`가 가상환경 · ffmpeg 경로 · UTF-8을 맞춰 부른다. 위치는 환경변수 `LECTURE_PY`(파이썬) · `LECTURE_BIN`(ffmpeg 폴더) · `LECTURE_FONTS`(localfonts.css)로 바꾼다. gpt 단계는 표준 파이썬만 있으면 된다.
